# Background music

Put a royalty-free dark/ambient track here named `dark_ambient.mp3`
(matches `music.path` in config.yaml).

Safe sources (no copyright strikes):
- YouTube Audio Library (free, in YouTube Studio)
- Pixabay Music, Uppbeat (free tier)
- Or generate with Stable Audio / MusicGen

Keep it quiet — `music.volume: 0.12` in config so the voice stays clear.
